# Contributing to Dopa-Direct

1. Read README.md, ACTIVITY_LOG.md and FEATURE_UPGRADE_PLAN.md.
2. Pick one bounded issue and state expected behavior.
3. Work on a feature branch.
4. Add tests for timer/state behavior and corrupted local data.
5. Document platform-specific requirements and privacy impact.
6. Open a PR with exact test commands, OS/version and results.
7. Append verified work to ACTIVITY_LOG.md.

Do not add telemetry, browser monitoring or network uploads without explicit opt-in, clear purpose and documented retention. Do not commit personal data or secrets. Human approval is required for releases.
