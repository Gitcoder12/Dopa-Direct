# Dopa-Direct — Company and Team Fit

Potential skill/employer fit only; no company use or endorsement is implied.

## Project thesis

A local Python tool that helps someone notice a distraction, choose a better next task and track short focus sessions.

## Microsoft

**Relevant areas:** Windows productivity, accessibility and developer experience.

**Potential roles:** Python Engineer, Developer Tools Engineer, Productivity Software Engineer, Windows Engineer or UX Engineer.

**Evidence:** Local-first Python CLI that records distraction triggers, recommends an activity, runs a focus timer and stores redirects/streaks/points in local JSON. The project includes an optional Windows Attention Guardian. It should not collect sensitive browsing content or claim to treat a health condition.
